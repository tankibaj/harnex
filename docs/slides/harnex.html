Coding with AI agents today

Fast at writing code.
Painful to ship.

  • It works on my machine.Then code review, QA or the deployment finds what the agent missed, and it’s my name on the PR.
  • I can’t explain my own code.The reviewer asks why. I scroll.
  • The PR is too big to review.40 files. My reviewer skims, approves, hopes.
  • The plan is too big to read.1,000 lines of Markdown. I approve it anyway.
  • It codes for my laptop.It never saw the deployment environment.

None of this is the agent’s fault. It just needs a workflow.

For developers using Claude Code, Codex or OpenCode

/harnex

Everything review would catch, caught before the PR.

  • Catches it first.The checks my reviewer would run, before the PR exists.
  • Writes less.The smallest change that works, readable in one pass.
  • Keeps PRs small.One purpose each. Big work becomes a series.
  • Keeps plans short.A few lines in chat. About 40 when it’s risky.
  • Tests my real setup.My repo’s own test and build commands, not a guess.
  • Any language, any stack.TypeScript, Swift, Python, Rust, Go, Bash… localhost, Docker or a local cluster.

Build & validate
↻ UP TO 3 ROUNDS
  1. Implementer writes a failing test, then the code.
  2. Validator runs tests, lint, scans, a browser walk. At the same time, a fresh reviewer reads the diff.
  3. UI reviewer checks the screens in a real browser. Only if the UI changed. QA writes test cases and, if you say yes, runs them for real.
  4. Findings? Must-fix or a failing test is fixed. Critical, or still failing after round 3: it asks you.
↻ Back to 2 and re-check only the fix.

Install

One line per agent.

# Claude Code
claude plugin marketplace add tankibaj/harnex && claude plugin install harnex@harnex
# Codex
codex plugin marketplace add tankibaj/harnex && codex plugin add harnex@harnex
# OpenCode and others
npx skills@latest add tankibaj/harnex -a opencode

Updates itself on Claude Code and Codex. Optional: a browser MCP for UI review and QA, e.g. claude mcp add playwright -- npx @playwright/mcp@latest.
